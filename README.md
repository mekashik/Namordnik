# Namordnik

> WPF-приложение для управления продукцией предприятия с использованием SQL Server.

Проект разработан в рамках учебной практики УП.04 (3 курс колледжа).

## ВОЗМОЖНОСТИ

Приложение предоставляет следующий функционал:

- просмотр продукции в виде карточек;
- поиск по названию, описанию и артикулу;
- фильтрация по типу продукции;
- сортировка по названию, цене и номеру цеха;
- просмотр материалов, используемых при производстве продукции;
- автоматический расчёт стоимости материалов;
- выделение продукции, которая не продавалась более месяца;
- добавление, редактирование и удаление продукции;
- массовое изменение стоимости выбранных товаров;
- постраничная навигация (пагинация).

## ИСПОЛЬЗУЕМЫЕ ТЕХНОЛОГИИ

- C#
- WPF (.NET Framework)
- XAML
- SQL Server
- ADO.NET

## ЗАПУСК ПРОЕКТА

### 1. Создание базы данных

Откройте **SQL Server Management Studio (SSMS)** и создайте новую базу данных с именем:

```text
Namordnik_DB
```

### 2. Импорт базы данных

Перейдите в папку:

```text
Database/
```

Откройте файл:

```text
Namordnik_DB.sql
```

Перед выполнением скрипта замените название сервера **USER-PC** на имя вашего SQL Server. После этого выполните весь SQL-скрипт.

### 3. Настройка строки подключения

Откройте файл:

```text
Resources/ConnectionStrings.cs
```

Замените

```csharp
Data Source=USER-PC;
```

на имя вашего сервера.

Например:

```csharp
Data Source=DESKTOP-ABC123;
```

### 4. Запуск приложения

Откройте решение в Visual Studio и запустите проект.

## СТРУКТУРА ПРОЕКТА

```text
Namordnik
│
├── Database/          # SQL-скрипт базы данных
├── Models/            # Модели данных
├── Resources/         # Константы и строка подключения
├── Services/          # Работа с базой данных
├── Views/             # Окна приложения
└── MainWindow.xaml    # Главное окно
```

## ОСОБЕНННОСТИ РЕАЛИЗАЦИИ

- работа с SQL Server через **ADO.NET**;
- разделение логики по сервисам (`ProductDatabaseService`, `MaterialDatabaseService`);
- использование параметризованных SQL-запросов;
- проверка подключения к базе данных при запуске приложения;
- валидация пользовательского ввода;
- запрет удаления продукции при наличии информации о продажах;
- автоматический расчёт стоимости материалов продукции;
- массовое изменение стоимости выбранных товаров;
- выделение продукции, не продававшейся последний месяц;
- постраничная навигация списка продукции.
