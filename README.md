## Namordnik

WPF desktop-приложение для управления продукцией, материалами и их стоимостью с использованием SQL Server. Проект разработан в рамках учебной практики УП.04 (3 курс колледжа).

## ОПИСАНИЕ:
Приложение представляет собой систему учёта продукции, которая позволяет:
- просматривать список продукции в виде карточек;
- искать, фильтровать и сортировать товары;
- просматривать материалы, используемые в производстве;
- рассчитывать стоимость материалов;
- выделять товары, которые не продавались за последний месяц;
- редактировать, добавлять и удалять продукцию;
- изменять стоимость выбранных товаров;
- работать с пагинацией списка.

## ТЕХНОЛОГИИ

- C#
- WPF (.NET Framework)
- SQL Server
- ADO.NET
- XAML

## ОСНОВНОЙ ФУНКЦИОНАЛ

ПРОДУКТЫ:
- отображение списка товаров в виде карточек;
- добавление новых продуктов;
- редактирование существующих продуктов;
- удаление продуктов;
- выбор нескольких товаров;
- изменение стоимости выбранных товаров.

ПОИСК И ФИЛЬТРАЦИЯ
- поиск по названию, описанию и артикулу;
- фильтрация по типу продукта;
- сортировка по названию, по цеху, по цене.

МАТЕРИАЛЫ:
- просмотр материалов каждого продукта;
- расчёт стоимости материалов;
- отображение количества и единиц измерения.
